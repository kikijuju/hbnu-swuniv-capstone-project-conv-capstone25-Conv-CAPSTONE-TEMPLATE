## <u>Teamate</u> Project Background

### 필요성
- 인공지능 모델의 발전과 함께 데이터가 클라우드로 집중되면서 전송 비용과 개인정보 유출 위험이 증가하고 있음.  
- 엣지 디바이스(스마트폰, IoT 기기 등)는 제한된 연산 자원을 가지고 있지만, 현장에서 발생하는 데이터를 실시간으로 학습에 활용할 수 있는 잠재력을 지님.  
- 클라우드 의존도를 줄이고, 엣지 환경에서도 효율적으로 모델을 학습할 수 있는 경량 연합학습 시스템이 필요함.

### 기존 해결책의 문제점
- 기존의 연합학습(Federated Learning, FL)은 서버와 클라이언트 간 통신량이 많아, 네트워크 대역폭이 제한된 엣지 환경에서 비효율적임.  
- 대부분의 기존 모델은 고성능 서버 환경을 전제로 설계되어, 저사양 디바이스에서는 학습 속도 저하와 모델 정확도 손실이 발생함.  

---

## System Design

### System Requirements
- 엣지 환경에서도 학습 가능한 경량화된 모델 구조 설계  
- 클라우드 의존도를 최소화한 분산형 학습 구조 구현  
- 통신 효율화를 위한 파라미터 압축 및 전송 최적화 기법 적용  
- TensorFlow Lite 및 PyTorch Mobile 기반의 시스템 구현  

---

## Case Study

### Description
본 연구에서는 IoT 센서 데이터 분류 문제를 대상으로 경량 연합학습 시스템의 성능을 검증하였다.  
라즈베리파이와 Jetson Nano를 엣지 디바이스로 사용하였으며, 각 디바이스는 자체 데이터를 이용해 부분 학습을 수행하였다.  
학습된 파라미터는 중앙 서버로 전송되어 평균화(FedAvg) 과정을 거쳐 통합 모델이 생성되었으며, 이를 다시 각 디바이스로 배포하여 반복 학습을 수행하였다.  

실험 결과, 중앙 집중식 학습 대비 데이터 프라이버시를 유지하면서 모델 정확도 92% 이상을 달성하였고, 통신량은 약 35% 감소하였다.

## Conclusion

### 연구 성과 요약
- 엣지 환경에서도 효율적으로 동작하는 경량 연합학습 시스템을 구현함.  
- 모델 경량화 및 통신 최적화를 통해 실시간 학습과 배포가 가능한 구조를 설계함.  

### 기대 효과
- 의료, 스마트홈, 산업 IoT 등 데이터 민감도가 높은 분야에서의 활용 가능성 증대.  
- 저비용·고효율의 엣지 인공지능 학습 구조로 차세대 AI 플랫폼 개발에 기여할 수 있음.
